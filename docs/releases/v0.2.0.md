# Bitaxe Fleet v0.2.0

Organize miners into workspaces, monitor each workspace on its own schedule, and use the dashboard more comfortably on a phone.

## Highlights

- Create, rename, switch, and delete empty workspaces. Each miner belongs to one workspace; moving it preserves its identity, preferences, and history. Historical charts follow its current workspace assignment.
- Set a collection interval and temperature unit independently for each workspace. Collection continues for every workspace while the browser is closed. Retention remains global.
- Explore fleet and device trends over the collection interval, 1 hour, 24 hours, or 7 days. The live range refreshes chart data without triggering extra miner polls. Device charts retain gaps around failed polls.
- Use the mobile navigation menu to switch workspaces and access settings, privacy, appearance, compatibility information, and the GitHub repository.
- Read the project's README in the dashboard. The About Bitaxe Fleet section also shows the application version.
- Hide workspace names with screenshot privacy and use the workspace list to control individual name visibility.

## Upgrade notes

- Back up the database and current installation before upgrading, then rebuild and restart both the API and collector. SQLite schema upgrades preserve miners and observations and place existing miners in the default workspace.
- Existing collection settings remain in effect until changed. Each workspace initially uses °C; the previous temperature preference was stored separately in each browser, so select °F again where desired.
- Node.js 22.22 or newer is required; Node.js 24 is recommended. The Docker setup uses Node.js 24.
- The 7-day chart shows only available retained history. Retention defaults to 24 hours; increasing it does not recover deleted readings.
- Workspaces are organizational groups, not separate accounts or security boundaries. The server still needs network access to all miners.

Bitaxe Fleet remains a read-only monitoring dashboard; miner configuration and controls stay in AxeOS.
